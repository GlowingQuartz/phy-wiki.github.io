Phy-Wiki

Solusi dan proses analitik fisika untuk berbagai kasus, kondisi, dan limit, dihimpun dari basis data, pustaka pribadi, internet, dan penyelesaian mandiri oleh AI.

Pengaturan

Kunci disimpan hanya di browser ini (localStorage) dan dikirim langsung ke penyedia. Jangan menaruhnya di repository.

Mendapatkan API key
  1. Gemini: buka Google AI Studio, masuk dengan akun Google, pilih Create API key, salin kuncinya.
  2. Claude: buka Anthropic Console, pilih Create Key; saldo kredit diperlukan.
Pencarian internet oleh AI memakai Google Search (Gemini) atau web search (Claude, harus diaktifkan di Console) dan dapat dikenai biaya.

Pustaka saya

Unggah buku atau solusinya (PDF, TXT, MD) yang Anda miliki, misalnya Griffiths. Teks diekstrak per halaman dan disimpan hanya di browser ini (IndexedDB), lalu ikut dicari dan dipakai AI sebagai rujukan berhalaman. PDF hasil pindai gambar tidak berisi teks dan tidak dapat dibaca.
